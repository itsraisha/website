Wazuh · Suricata · Auditd · AWS

Open-source SOC / SIEM with Wazuh, Suricata and Auditd

Built a small SOC using an AWS hive-sensor architecture. Simulated an external Kali attack chain with Nmap reconnaissance, Hydra SSH brute force and post-exploitation file activity. Correlated Suricata network alerts, SSH/PAM authentication logs and Auditd host telemetry in Wazuh.

Application security hardening case study

Hardened an open-source hospital management application against stored XSS, IDOR, plaintext credential storage, broken access control, missing admin session validation, unlimited login attempts and directory browsing. Mapped security goals to OWASP Top 10 and ASVS, then retested the fixes.
